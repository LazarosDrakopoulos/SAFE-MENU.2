# SAFE-MENU.2

## Live demo
https://lazarosdrakopoulos.github.io/SAFE-MENU.2/

"Safe Menu" is a web application designed to help users make safer food choices based on their allergies.
This project was created as part of my journey into programming, inspired by my real-world experience as a pastry chef.

## Overview
Working in the kitchen, I see every day how important it is for customers to understand what is in their food—especially when allergies are involved. Even small ingredients can have a serious impact, and not everyone feels comfortable asking for details.
Safe Menu aims to solve this problem in a simple and user-friendly way.


## Features
* Select common allergies (e.g. nuts, milk, gluten)
* Add custom allergies
* Filter menu items based on selected allergies
* Clear and simple user interface

## How It Works
1. Open the application
2. Select your allergies
3. View menu items that are safe for you
