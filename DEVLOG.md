The Reality Check First
There is no free API that gives you a real restaurant menu with allergen data. This is the honest truth after research. Here's why:

Real restaurant menus are proprietary — no restaurant shares their menu via a public API
APIs that exist either require a key + payment, scrape delivery platforms (legally grey), or give you generic recipe data (not restaurant menus)
The only 100% free, no-key, production-ready APIs give you dishes + images + ingredients — which is exactly what we need, and we can map allergens ourselves

I choose TheMealDB because ingredients are listed, so we detect allergens ourselves
